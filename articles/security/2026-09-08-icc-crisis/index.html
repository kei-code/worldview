FILE 01論点

2023年3月、国際刑事裁判所（ICC）はウラジーミル・プーチン大統領に逮捕状を発付した。2024年11月には、ベンヤミン・ネタニヤフ首相にも。だがその後、両氏は逮捕状の効力が及ぶはずの加盟国を訪問しながら、一度も拘束されていない。

ICCは常設の国際刑事法廷として2002年に設立され、ローマ規程に基づき125か国が締約国として加盟する。だがICC自身は警察組織を持たず、逮捕を実行する権限がない。逮捕状の執行は各締約国の国内当局に委ねられており、法の効力が現実の拘束に変わるかどうかは、各国政府の政治判断にかかっている。

締約国が理論上負う協力義務は、政治的なコストの前でどこまで守られるのか。そしてアメリカによる制裁攻勢と、検察官解任という内部危機が同時に進むいま、この制度そのものは持ちこたえられるのか。
管轄の壁
アメリカ・ロシア・イスラエル・中国など、国連安保理常任理事国を含む主要国の多くがローマ規程を批准していない。これらの国の指導者は、ICCの管轄権そのものを認めない立場を取れる。
執行力の欠如
ICCには独自の警察力がない。逮捕状を出せても、対象者を拘束できるかは、その人物が足を踏み入れた締約国政府の意思次第。強制する上位機関は存在しない。
政治的コスト
現職の国家元首や首相を自国領内で拘束すれば、相手国との関係は決定的に悪化する。締約国であっても、外交・安全保障上の利害が絡めば、義務より実利が優先されやすい。
証拠書類 「締約国は、この規程に従い、裁判所の管轄権の範囲内にある犯罪について裁判所が行う捜査及び訴追において、裁判所に対し十分に協力する」 — ローマ規程 第86条（協力の一般的義務）

FILE 05深掘り

ICCが直面しているのは単一の攻撃ではない。管轄権の限界という制度設計上の欠陥、締約国の及び腰、非締約国からの解体圧力、内部の統治危機——これらが重なった構造を4つの観点から見る。

所見 01
常任理事国3カ国が非締約国という構造的欠陥
国連安全保障理事会の常任理事国5カ国のうち、アメリカ・ロシア・中国の3カ国はローマ規程を批准していない。世界の平和と安全に最も大きな責任を持つはずの国々が、国際刑事司法の枠外に立っている。ICCの管轄権は締約国の同意に基づく以上、この構造は変えようがない。
所見 02
検察官解任のタイミングが示す、内部からの正統性侵食
カリム・カーン氏への疑惑は2024年に浮上し、ネタニヤフ氏らへの逮捕状発付とほぼ同時期だった。国連の外部調査は不品行を認定する事実はないとしたにもかかわらず、締約国会議の監督機関は逆の結論を出し解任に至った。逮捕状を主導した本人が排除されたことで、ICCは外からの制裁に加え、内部の統治過程への疑念も抱えることになった。
所見 03
「面従腹背」の代償 — モンゴルは免れ、ハンガリーは政権ごと変わった
締約国であっても、政治的な思惑で義務が履行されないことがある——だが02で見たように、結末は一様ではない。モンゴルは義務違反を認定されながら、実質的な代償を払っていない。一方、ネタニヤフ氏を拘束しなかったハンガリーのオルバーン政権は、2026年4月の総選挙で敗北し、後継の親欧州連合派政権は脱退方針そのものを撤回した。締約国の姿勢は、政権交代という国内政治の過程を通じて変わりうることを、この一件は示している。
所見 04
資金・人的基盤の持続可能性
締約国からの分担金に依存するICCにとって、アメリカからの制裁は職員個人の資産凍結にとどまらず、銀行や協力機関がICCとの関わりを避ける萎縮効果を生みかねない。主要な資金拠出国である欧州諸国がどこまで支持を継続できるかが、今後の存続を左右する。

紙の上の約束は、守られなかった。逮捕状が誰にも執行されないという現実は、単なる一時的な機能不全ではなく、国際法そのものが持つ構造的な限界を映し出している。
