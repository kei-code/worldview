国連は死んだのか
— 安保理の機能不全と「ルールなき世界」

ガザの停戦も、ウクライナ侵攻の非難も、安保理は止められなかった。拒否権を持つ5つの大国の利害が一致しなければ、世界の最高意思決定機関は何も決められない。だがこの麻痺は「欠陥」なのか、それとも創設時からの「設計どおり」なのか。改革は80年間進まず、秩序づくりの舞台は国連の外——BRICS・G20・クアッドへと移り始めた。国連の機能不全の正体を、6つの立場から読み解く。

01核心と問い — 欠陥か、設計どおりか

安保理が何も決められないのは、制度の「故障」なのか、それとも「仕様」なのか。拒否権は、大国の暴走を止めるブレーキとして設計された。だが今やそれは、大国が自らの責任を問われないための盾になっている。国連は機能不全に陥ったのか——それとも最初から、こういうものだったのか。

国際連合（国連）は1945年、第二次世界大戦の惨禍を二度と繰り返さないために生まれた。その中核が、国際の平和と安全に第一の責任を負う安全保障理事会（安保理）だ。総会が193の全加盟国による「議論の場」だとすれば、安保理は制裁や武力行使を法的拘束力をもって決められる「執行の場」である。だが、その執行力の鍵を握るのが、第二次大戦の戦勝国であるアメリカ・イギリス・フランス・ロシア（旧ソ連）・中国の5常任理事国に与えられた「拒否権」だ。この5カ国のうち1カ国でも反対すれば、ほかの14カ国がいかに賛成しても、決議は成立しない。

この設計には明確な思想があった。大国を強制的に従わせようとすれば、大国同士の戦争になる——その教訓から、「大国が一致しないことは、そもそも実行しない」という安全装置を組み込んだのだ。だから安保理の麻痺は、ある意味で意図された結果でもある。問題は、その装置が今、ガザやウクライナのように大国自身が当事者となる危機の前で、責任回避の道具として使われていることだ。本記事は、この機能不全を3つの構造から捉える。

機能不全を生む3つの構造
拒否権 — 設計に組み込まれた麻痺
常任5カ国の一票が決議全体を葬る。とりわけ大国自身やその同盟国が当事者の場合、当事者が裁判官を兼ねる構造になる。ロシアは自国のウクライナ侵攻への非難を、アメリカはイスラエルへの圧力を、それぞれ拒否権で阻んできた。
代表性 — 1945年で止まった世界
加盟国は51から193へ約4倍になったが、常任理事国の顔ぶれは80年間不変だ。人口14億のインドも、経済大国の日本・ドイツも、54カ国を擁するアフリカも常任の座を持たない。「戦勝国クラブ」が世界を代表しているという正統性が揺らいでいる。
強制力 — 決めても動かせない
国連は独自の常備軍を持たない。決議が通っても、実際に動くのは加盟国が自発的に出す部隊や資金だ。国連平和維持活動（PKO）も派遣国の意思に依存する。「決める力」と「動かす力」が分離しているため、決議は時に紙の上の宣言にとどまる。
用語解説
拒否権（veto）と常任理事国

安保理は15カ国で構成され、うち5カ国（アメリカ・イギリス・フランス・ロシア・中国）が任期のない「常任理事国」、残り10カ国が地域ごとに選ばれる任期2年の「非常任理事国」だ。重要事項の決議には9カ国以上の賛成が必要だが、常任理事国が1カ国でも反対票を投じると、その時点で否決される。これが拒否権で、常任理事国だけに与えられた特権である。手続き事項には適用されない。

036つの視点

拒否権擁護（常任理事国の論理） 秩序の安全弁
「大国を無理に従わせれば、それは新たな大国間戦争の引き金になる」
麻痺は機能の代償 拒否権は失敗ではなく設計だ、というのが常任理事国の基本的立場。大国の合意なき強制は実行できないし、強行すれば世界大戦のリスクを高める。安保理が動かないのは、動かすべきでない局面だからだ、という論理である。
既得権としての防衛 表向きは安定の論理を語りつつ、5カ国は拒否権という特権を手放す気はない。改革で新常任が増えれば自らの相対的影響力は下がる。「制度を守る」主張と「特権を守る」動機が分かちがたく結びついている。
この問題との関係の深さ
改革推進派（日本・ドイツ・インド・ブラジル） 常任入りを求める
「21世紀の世界を、1945年の権力構造で運営することはできない」
常任議席の拡大 経済・人口・拠出で重みを増したG4（日本・ドイツ・インド・ブラジルの4カ国）は、安保理を25議席前後に拡大し、自らを含む新常任を加える案を主導する。代表性を回復しなければ安保理の正統性は持たない、という訴えだ。
拒否権の凍結という妥協 抵抗を和らげるため、新常任の拒否権は10〜15年凍結する案も示す。だが憲章改正には常任5カ国を含む3分の2の賛成が必要で、既存5カ国が自らの相対的地位を下げる改革に応じる保証はない。
この問題との関係の深さ
グローバルサウス（アフリカ連合ほか） 歴史的不正義の是正
「植民地だった大陸が、世界の意思決定の中心にひとつの常任議席も持たない」
アフリカの代表性 54カ国・14億人を擁するアフリカは常任議席ゼロだ。アフリカ連合は「エズルウィニ・コンセンサス」で、拒否権付きの常任2議席＋非常任5議席を要求する。安保理の議題の多くがアフリカに関するものでありながら、当事者が決定の輪の外にいる。
「二重基準」への不信 ウクライナには厳しく、ガザには甘い——西側の対応の落差が、グローバルサウスの国際秩序への不信を深めた。ルールが大国の都合で伸縮するなら、そのルールに従う義理はない、という空気が広がっている。
この問題との関係の深さ
国連擁護・人道機関 安保理＝国連ではない
「安保理が麻痺しても、毎日何億人もが国連の活動で生かされている」
見えない実務の価値 世界食糧計画（WFP）、難民を支える国連難民高等弁務官事務所（UNHCR）、世界保健機関（WHO）——安保理の政治的麻痺とは別の次元で、国連の専門機関は食料・難民・保健・気候の現場を支えている。「国連は死んだ」という断定は、この実務を見落としている。
不完全でも不可欠 安保理が完璧に機能した時代はそもそも存在しない。それでも各国が対話する常設の場、規範を語る共通の言語としての価値は失われていない。壊すより、不完全なまま使い続けるべきだという立場だ。
この問題との関係の深さ
現実主義・懐疑論 過大評価への警告
「国連はもともと世界政府ではない。大国が合意を確認する鏡にすぎない」
力の現実を映すだけ 国際政治の現実主義者は、安保理は独立した権力ではなく、大国間の力関係を映す鏡だと見る。鏡が割れて見えるのは、世界の力配分が多極化して割れているからだ。安保理に過剰な期待をかけること自体が間違いだ、という醒めた立場。
改革論の空疎さ 議席を増やしても、拒否権を残せば麻痺は続き、拒否権を廃せば大国は離脱する。どちらにせよ機能はしない——改革の議論は、解けないジレンマを言葉で覆い隠しているにすぎない、と懐疑論は指摘する。
この問題との関係の深さ
「小さな多国間主義」推進派 国連の外で動く
「全員一致を待つより、動ける有志だけで動く方が早い」
有志連合への移行 G7・G20、拡大するBRICS（ブラジル・ロシア・インド・中国・南アフリカで発足した新興国連合）、クアッド（日本・アメリカ・オーストラリア・インドの4カ国枠組み）——課題ごとに動ける国だけが集まる「クラブ外交」が増えている。拒否権に縛られない機動性が魅力だ。
分断という副作用 ただし、これは普遍的なルールの場を、立場の近い者同士の小さな輪に置き換える動きでもある。BRICS＋は世界人口の45%を代表するが、西側のクラブと東側のクラブが並び立てば、世界はむしろ二極・多極へと分断されかねない。

05深掘り — 「死」の先にあるもの

拒否権は「欠陥」か「機能」か
拒否権を単なる欠陥と見なすのは早計だ。それは「大国を強制すれば大戦になる」という第二次大戦の教訓から、意図して組み込まれた安全装置だった。実際、拒否権があるからこそ大国は国連にとどまり、最悪の直接衝突は避けられてきた側面がある。問題は、この装置が本来の「大国間戦争の抑止」を超えて、大国が自国や同盟国の行動への批判を封じる盾として使われていることだ。設計思想は正しくとも、運用が目的を裏切っている——機能不全の核心はそこにある。
改革はなぜ80年も進まないのか
安保理改革が進まない理由は、構造そのものに埋め込まれている。改革には国連憲章の改正が必要で、それには総会の3分の2の採択に加えて、全加盟国の3分の2（常任5カ国すべてを含む）の批准が要る。つまり、特権を最も削られる側の同意がなければ、特権を削れない。さらに新常任の候補をめぐっても、日本に中国が、インドにパキスタンが、ドイツにイタリアが反対するなど、地域内のライバル関係が合意を阻む。「総論賛成・各論反対」の典型例であり、80年間ほぼ動かなかったのは偶然ではない。
「小さな多国間主義」は代替になるか
安保理が動かないなか、G20やBRICS＋、クアッドといった有志連合が存在感を増している。拒否権に縛られず、課題ごとに動ける国だけが集まる機動性は確かに強みだ。だが、これらは普遍的な正統性を持たない。誰が入り、誰が排除されるかは力関係で決まり、ルールは内輪の合意にとどまる。西側のクラブと非西側のクラブが並び立てば、世界は一つの秩序ではなく、複数の競合する秩序へと分かれていく。機動性の代償は、普遍性の喪失かもしれない。
「ルールなき世界」で日本はどう動くか
日本は安保理改革の主導国（G4）であり、最大級の国連分担金を負担する「国連重視」の国でもある。だが常任入りの展望は開けず、頼みの国際秩序は揺らいでいる。普遍的ルールの空洞化は、軍事力で劣りルールに守られてきた中堅国にこそ打撃が大きい。安保理改革を訴え続けながら、同時にクアッドのような有志連合にも軸足を置く——その二正面の使い分けが、当面の現実的な選択肢になる。理想の制度を待つのではなく、不完全な複数の枠組みを束ねて使う外交が問われている。
